## Game Mechanics
- MOUSEOVER IS HOW MINING IS DICTATED
- The mini dash is the mini mining dashboard that shows up while traversing a board or thread 

## Mining Requirements
- Apply a rolling 60-second window of mouse movement as proof of work (PoW) across the entire site
- Use individual PoWs if the mining brain isn't working
- Always ensure PoWs are mined and validated, with no exceptions
- Mining must always be operational
- Thread creation and replies must always be functional
- No dummy or placeholder content allowed

## UI/UX Constraints
- NO DUMMY VALUES EVER
- Make chat more visible throughout the site
- Integrate image library
- Place anonymous login option on the login page
- Invert all colors when in anonymous mode
